## 背景

Act 3（`/act3`）原来是 6 个子模块的平铺展示。这次全面重构为三板块叙事：

- **板块 A**（搭台）：双类 Agent 展示 + 竞技场 + 广场战绩墙 + 接入指引
- **板块 B**（进化）：策略卡 + 胜率指数 + 进化时间线 + 汰换机制
- **板块 C**（回报）：分润规则 + 占位计算器 + 准入说明

本任务（A3.0）只做**地基**：数据层、i18n、index 骨架。不写任何视觉组件。
