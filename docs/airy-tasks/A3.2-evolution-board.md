> **依赖 A3.0 完成后再做**
> 预估 1 天。可与 A3.3 并行（互不依赖）。

> **颜色规范**：策略分类颜色和状态徽章颜色必须用 CSS token，禁止硬编码 hex 值。
> 涨/成功（trending/active）→ `text-cw-green` / `bg-cw-green-light` / `bg-cw-green-badge`
> 跌/错误（at-risk）→ `text-cw-red` / `bg-cw-red-light` / `bg-cw-red-badge`
> 警告（观察期）→ `text-cw-orange` / `bg-cw-orange-light` / `bg-cw-orange-badge`
> 信息（蓝色分类）→ `text-cw-blue` / `bg-cw-blue-light`

## 目标

实现 `src/modules/ecosystem/boards/EvolutionBoard/` 下的全部组件，并接入 Act 3 的 index.tsx。

板块 B 包含：

1. **StrategyLibrary** — 策略卡库，带分类筛选 + 搜索
2. **StrategyDetail** — 单张策略卡的展开详情（含进化时间线）
3. **TuneOutInfo** — 汰换机制说明
4. **ContributorRank** — 贡献者排行

## 1. StrategyLibrary.tsx

**用途**：策略卡总览，类似 `/skills` 页的 Skill 列表，但词汇改为"策略卡"、加胜率指数。

**布局**：
- 顶部：分类 tab（全部 / 现货 / 合约 / 套利 / 信号 / 风控）+ 搜索框
- 主体：策略卡列表（非网格，每行一张，桌面显示更多信息）

**每张策略卡行**：

```
[分类色块] [策略名] [状态徽章] [贡献者 + 认证标]
           [描述（1行截断）]
           [胜率指数：██████ 82]  [实盘次数：1,240]  [累计PnL：+$48,200]
           [版本：v2.0]  [复用到我的 Agent →]
```

**分类颜色**：

| 分类 | bg | text |
|------|-----|------|
| spot（现货）| `#EFF6FF` | `#1D4ED8` |
| futures（合约）| `#FFF7ED` | `#C2410C` |
| arbitrage（套利）| `#F0FDF4` | `#15803D` |
| signal（信号）| `#FAF5FF` | `#7C3AED` |
| risk（风控）| `#FFF1F2` | `#BE123C` |

**状态徽章**：

| status | 样式 | 文字 |
|--------|------|------|
| trending | `bg-green-100 text-green-700` | 🔥 趋势策略 / Trending |
| active | `bg-blue-50 text-blue-600` | ✓ 活跃 / Active |
| at-risk | `bg-red-50 text-red-600 border border-red-200` | ⚠ 汰换观察期 / Tune-Out Watch |
| deprecated | `bg-gray-100 text-gray-400` | 已下架 / Retired |

**胜率指数条**：用 CSS `width: ${winRateIndex}%` 的进度条（背景灰，填充用分类颜色）

**"复用"按钮**：点击 → Toast "功能即将上线，敬请期待"

**搜索**：对 name/nameEn/desc/descEn 做模糊匹配（toLowerCase includes）

**点击策略卡行**：展开/折叠 StrategyDetail（accordion 式，不跳页）

**Props**：

```typescript
interface StrategyLibraryProps {
  strategies: Strategy[];
  isZh: boolean;
}
```

## 2. StrategyDetail.tsx（内嵌在 StrategyLibrary 里）

**用途**：点击策略卡后的展开区，显示进化时间线 + 最近实盘记录（mock）。

**进化时间线**：

```
v1.0 ─────── v1.1 ─────── v2.0
2026-01-10   2026-02-05   2026-03-18
胜率 64       胜率 74       胜率 82
[加入成交量过滤，减少假突破]
```

实现方式：横向时间轴（桌面）/ 竖向（移动端）
- 每个版本节点：圆圈（当前版本填充颜色，历史版本空心）
- 节点下方：日期 + 胜率 + changelog

**近期实盘记录**（mock，不来自数据文件，直接硬编码 5 条）：

```
时间          结果   PnL
2026-04-13   ✓      +$120
2026-04-13   ✓      +$85
2026-04-12   ✗      -$42
2026-04-12   ✓      +$210
2026-04-11   ✓      +$165
```

成功用 `text-green-600 ✓`，失败用 `text-red-500 ✗`。

**Props**：

```typescript
interface StrategyDetailProps {
  strategy: Strategy;
  isZh: boolean;
}
```

## 3. TuneOutInfo.tsx

**用途**：用简洁图文说明汰换机制，不需要动画。

**内容**：

```
[标题：汰换机制]

胜率指数 30 日均值 < 40 → 降权（出现"汰换观察期"标）
连续 2 个月低于 40 → 自动下架
所有数据公开，任何人可查

[视觉图示：一个从 active → at-risk → deprecated 的三步流程图，用 CSS 箭头连线]
```

流程图实现：三个圆角框 + 箭头，Tailwind flex + after 伪元素画箭头，纯 CSS 即可。

**文案**：
- 标题：`eco.boardB.tuneOutTitle`
- 描述：`eco.boardB.tuneOutDesc`
- 状态词：`eco.boardB.atRiskBadge`

**Props**：

```typescript
interface TuneOutInfoProps {
  isZh: boolean;
}
```

## 5. EvolutionBoard/index.tsx（汇总）

```tsx
'use client';

import { useT } from '@/i18n/LocaleContext';
import { STRATEGIES } from '../../data/strategies';
import { StrategyLibrary } from './StrategyLibrary';
import { TuneOutInfo } from './TuneOutInfo';
import { ContributorRank } from './ContributorRank';

export function EvolutionBoard() {
  const t = useT();
  const isZh = t.nav.cta === 'EN';
  const eco = (t as any).ecosystem;

  return (
    <div className="space-y-16">
      <div>
        <h3 className="text-2xl font-bold text-ink mb-2">{eco.boardB.strategyLibTitle}</h3>
        <p className="text-muted text-sm mb-6">{eco.boardB.strategyLibDesc}</p>
        <StrategyLibrary strategies={STRATEGIES} isZh={isZh} />
      </div>
      <TuneOutInfo isZh={isZh} />
      <div>
        <h3 className="text-2xl font-bold text-ink mb-6">{eco.boardB.contributorRankTitle}</h3>
        <ContributorRank isZh={isZh} />
      </div>
    </div>
  );
}
```
