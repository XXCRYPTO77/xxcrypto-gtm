# A2.1 — SkillDiscovery 组件（Act 2 Step 1）

**分支**：`feat/airy-a2.1-skill-discovery`
**文件**：`src/modules/agent-chat/components/SkillDiscovery.tsx`
**预估工时**：2-3h

---

## 背景

Act 2 是 6 步用户旅程：发现 → 选 Agent → 绑 API → 对话 → 执行 → 复盘。

Step 1 = **SkillDiscovery**。用户进入 Act 2 看到的第一屏，任务是让用户理解"CoinW 有 18 项 Skills 可用"，然后点击进入 Step 2。

F 已经在 `modules/agent-chat/index.tsx` 里留好了接入点（lazy require），你交付后自动生效。

## 目标

做一个"Skill 发现"页面，展示 18 项 Skills，给用户"这东西能做啥"的直观感受，然后引导进入下一步。

## 数据源

已经建好，直接 import：

```tsx
import { CHAT_SKILLS, type SkillRef } from '../data/skills';
```

`CHAT_SKILLS` 当前是 12 项（信息 4 + 交易 4 + 认证 2 + 平台 2）。你可以直接补全到 18 项——把 landing 模块 `src/modules/landing/data/capabilities.ts` 里的 M1-M18 对应映射过来（skills.ts 里加 6 条）。

**注意**：skills.ts 的 `SkillRef` 字段是 `{ code, name, nameEn, group }`，和 landing capabilities 的 `{ code, name, desc, group }` 不完全对齐。你只需要加 name/nameEn/group，不要 desc。

补全后的 group 分布建议：info 4 / trade 6 / auth 4 / platform 4。

## 接口约定

```tsx
interface SkillDiscoveryProps {
  onNext: () => void;
}

export function SkillDiscovery({ onNext }: SkillDiscoveryProps) { ... }
```

**导出名必须是 `SkillDiscovery`**（named export，不是 default）——`modules/agent-chat/index.tsx` 里是这样 require 的。

## UI 要求

**整体节奏**：标题 + 筛选/搜索 + 卡片墙 + CTA。

1. **Hero 区**：
   - 大标题："18 项 Skills，覆盖加密交易全流程" / "18 Skills, full crypto trading stack"
   - 副标题一句话说明
   - 右上角：搜索框（按 name / code 过滤）

2. **分组筛选 Tab**：
   - "全部 / 信息 / 交易 / 认证 / 平台"
   - 点击筛选卡片墙

3. **卡片墙**（grid，3 列桌面 / 2 列平板 / 1 列手机）：
   - 每张卡：code（徽章）+ name + group 色标 + 悬停高亮
   - 卡片点击 → toast "已标记感兴趣" 或展开一句话描述（二选一，看你觉得哪个更自然）
   - 已被"标记"的卡加勾选状态

4. **底部 CTA**：
   - 选了至少 1 个 skill → "基于你的选择推荐 Agent →"
   - 没选 → "跳过，看所有 Agent →"
   - 两个按钮都触发 `onNext()`

**视觉锚点**：沿用 Act 1 风格，`text-ink / text-muted / bg-brand-soft / text-brand`。不要引入新颜色。参考 `src/modules/landing/components/CapabilityTabs.tsx` 的分组 tab 实现。

## i18n

不走 global i18n，也不建模块级 i18n（Act 2 目前文案直接写在组件/数据里）。

判断 zh/en 的方式：
```tsx
import { useT } from '@/i18n/LocaleContext';
const t = useT();
const isZh = t.nav.cta === 'EN';
```

然后 `{isZh ? '中文' : 'English'}`。
