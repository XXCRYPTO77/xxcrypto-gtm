# Airy 任务包 · A1.1 — capabilities.ts 数据文件

**优先级**：P0（并行 A1.2 + A1.3 一起做）  
**预估工时**：2h  
**分支**：`feat/airy-a1.1-capabilities`  

---

## 任务目标

建 `src/modules/landing/data/capabilities.ts`，存储 M1-M18 能力数据。  
关键要求：**用用户语言**写描述，不是内部系统视角。

---

## 接口定义（照这个写，不要改）

```typescript
// src/modules/landing/data/types.ts
export type CapabilityGroup = 'info' | 'trade' | 'auth' | 'platform';

export interface Capability {
  code: string;          // "M1"
  name: string;          // 简短名称（≤8字）
  desc: string;          // 用户语言描述（≤25字），"帮你..."开头
  group: CapabilityGroup;
}
```

---

## 数据内容

原始数据（当前系统视角，需要改写成用户视角）：

| code | group | 原始 name | 原始 desc（系统视角） |
|------|-------|-----------|----------------------|
| M1 | info | 实时行情查询 | 价格 K 线深度成交，一切的起点 |
| M2 | info | 涨跌排行 | Agent 筛选标的的基础 |
| M3 | info | 交易所公告 | 上币维护规则变更，直接影响决策 |
| M4 | info | 多语言返回 | Skill 描述和结果支持多语言 |
| M5 | trade | 现货合约下单撤单 | 限价市价，交易闭环的核心 |
| M6 | trade | 订单查询 | 当前挂单 + 历史，Agent 决策前提 |
| M7 | trade | 余额查询 | 可用 + 冻结，下单前置检查 |
| M8 | trade | 持仓总览 | 盈亏概览，Agent 理解当前仓位 |
| M9 | trade | 划转 | 各钱包间划转，现货要有钱才能现货下单 |
| M10 | trade | 禁止提现 | 风控硬红线 |
| M11 | auth | API Key 认证 | 真金白银的底线 |
| M12 | auth | 权限分级 | 只读 / 现货 / 合约 / 完整，最小权限 |
| M13 | auth | 频率限制 | 防滥用，保护系统稳定 |
| M14 | auth | 额度上限 | 单笔 + 日累计 |
| M15 | platform | MCP 协议服务 | Agent 接入的唯一方式 |
| M16 | platform | Skills 可发现性 | Agent 找不到就没意义 |
| M17 | platform | 站内落地页 | 展示 + 接入 + API Key 生成入口 |
| M18 | platform | 基础调用统计 | 效果验证最小数据支撑 |

**改写规则**：
- desc 改成"帮你..."开头，写用户得到什么，不写系统做了什么
- name 可以微调成更口语的说法（原始 name 用的是后台术语）
- 例子：M1 → name="实时行情" desc="帮你随时查 BTC 价格、K 线和成交量"
- 例子：M10 → name="禁止提现" desc="帮你锁住提现权限，Agent 只能交易不能把钱提走"
