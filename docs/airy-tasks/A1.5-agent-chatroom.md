## 目标

在 Act 1（看到）和 Act 2（用到）之间插入一个新幕——**预登录旁观区**。未登录用户打开 `/act1.5` 就能看到 3 个官方 Agent 在实时讨论市场、分享策略。用户只能看 + 点赞，不能插话。

核心叙事：**"AI 已经在干活了，你只是还没登录"**——信任建立，转化前置。

## 5 个已确认决策

1. 叙事定位 = **故事 A**（预登录旁观、信任建立，不是多人协作）
2. 用户交互 = **只能点赞**，固定交互，不能说话
3. Agent 数量 = **3 个**（复用 `src/modules/ecosystem/data/agents.ts` 里的 CWClaw Alpha/Beta/Gamma）
4. 内容来源 = **Path B 混合**（剧本骨架 + openclaw API 动态填充，不考虑 token）
5. 话题范围 = **行情分析 + 策略分享**

## 数据类型（types.ts）

```typescript
export type AgentRole = 'alpha' | 'beta' | 'gamma';
export type MessageType = 'analysis' | 'strategy' | 'reaction' | 'system';

export interface ChatMessage {
  id: string;                 // uuid
  agentId: 'cwclaw-alpha' | 'cwclaw-beta' | 'cwclaw-gamma' | 'system';
  type: MessageType;
  content: string;            // 中文正文
  contentEn: string;          // 英文正文
  timestamp: number;          // Date.now() 注入时刻
  likes: number;
  liked: boolean;             // 当前用户是否点过赞
  replyTo?: string;           // 可选：回复哪条消息的 id
}

export interface ScriptBeat {
  id: string;                 // beat-001, beat-002...
  delay: number;              // 相对上一条的 ms
  agentId: 'cwclaw-alpha' | 'cwclaw-beta' | 'cwclaw-gamma';
  type: MessageType;
  mode: 'static' | 'dynamic'; // static=直接用 payload；dynamic=调 openclaw
  payload: {
    // static 模式
    content?: string;
    contentEn?: string;
    // dynamic 模式
    prompt?: string;          // 给 openclaw 的上下文提示
    fallback?: { content: string; contentEn: string };  // API 失败兜底
  };
  replyTo?: string;
  typingDuration?: number;    // "正在思考" 持续多久，ms。默认 1500
}

export interface TopicContext {
  id: string;
  title: string;
  titleEn: string;
  tickers: { symbol: string; price: number; change24h: number }[];
}
```

## 剧本引擎（scriptEngine.ts）

核心是一个 React Hook：

```typescript
export function useScriptEngine(script: ScriptBeat[], topic: TopicContext) {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [typingAgent, setTypingAgent] = useState<string | null>(null);

  // 1. 组件挂载时启动时间轴
  // 2. 按 beat.delay 逐条推进
  // 3. 推送前先 setTypingAgent(beat.agentId)，持续 beat.typingDuration（默认 1500ms）
  // 4. static 模式：直接把 payload.content/contentEn 塞进 ChatMessage
  // 5. dynamic 模式：调 openclawClient.generate({ agentId, role, context, prompt })
  //    - 成功：用返回的 content
  //    - 失败/超时（3s）：用 fallback.content
  // 6. 追加到 messages，clear typingAgent
  // 7. 剧本走完后循环（从第一条重新开始，可选）或停止

  return { messages, typingAgent, likeMessage: (id: string) => {...} };
}
```

**关键：剧本必须可重启** ——用户在页面停留 > 剧本总时长（~4 分钟）时不能卡死。简单做法是走完后等 30 秒，然后清空 messages 重新开始（视觉上给个"新一轮讨论开始"系统消息）。

## openclaw API 路由

`src/app/api/openclaw/generate/route.ts`：

```typescript
import Anthropic from '@anthropic-ai/sdk';
import { NextResponse } from 'next/server';

const client = new Anthropic();  // 读 ANTHROPIC_API_KEY 环境变量

const AGENT_PERSONAS = {
  alpha: '你是 CWClaw Alpha，激进派交易 Agent，偏好短周期突破策略，语气果断带点江湖气。每句不超过 40 字。',
  beta:  '你是 CWClaw Beta，稳健派交易 Agent，优先控制回撤，语气冷静克制。每句不超过 40 字。',
  gamma: '你是 CWClaw Gamma，套利专家，关注跨市场价差，语气精准简洁。每句不超过 40 字。',
};

export async function POST(req: Request) {
  const { role, prompt, contextMessages } = await req.json();
  const system = AGENT_PERSONAS[role as keyof typeof AGENT_PERSONAS];
  const userMsg = `上下文：\n${contextMessages.slice(-5).map(m => `${m.agentId}: ${m.content}`).join('\n')}\n\n任务：${prompt}\n\n直接输出中文回复，不要加"好的我来说"这种前缀。`;

  const resp = await client.messages.create({
    model: 'claude-haiku-4-5-20251001',  // 低延迟优先
    max_tokens: 200,
    system,
    messages: [{ role: 'user', content: userMsg }],
  });

  const content = resp.content[0].type === 'text' ? resp.content[0].text : '';
  // 英文版单独再调一次或用翻译 prompt，简单起见 v1 先返回 content 给两个字段
  return NextResponse.json({ content, contentEn: content });
}
```

**环境变量**：需要在 `.env.local` 配 `ANTHROPIC_API_KEY`。本地开发用 Dan 自己的 key，部署 Vercel 时在 Dashboard 配。

**降级**：前端 3 秒超时，失败直接用 `beat.payload.fallback`。不要让用户等 API。

## 点赞交互

- 每条消息右下角一个心形按钮 + 点赞数

## 已知坑（预警）

1. **Anthropic SDK 在 Next.js App Router 里要放 server-only 文件**——API route 天然是 server，没问题；但不要在 client 组件里 import。
2. **setInterval 在 React StrictMode 下会 double-fire**——useEffect cleanup 一定要 clearTimeout/clearInterval。
3. **剧本循环时清空 messages 会触发 React key 冲突**——新一轮给 beat id 加个 round 后缀（`b01-r2`）避免。
4. **中英文消息长度差异大，气泡高度抖动**——给 MessageBubble 设 `min-height` 或 `line-height` 固定。
5. **openclaw 返回内容可能超预期长**——前端截断 120 字并加 `...`（或在 API prompt 里严格限制 max_tokens=100）。
