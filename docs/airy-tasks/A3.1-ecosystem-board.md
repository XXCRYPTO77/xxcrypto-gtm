## 目标

实现 `src/modules/ecosystem/boards/EcosystemBoard/` 下的全部组件，并接入 Act 3 的 index.tsx。

板块 A 包含五个子区块，从上到下：

1. **NetworkTopology** — 动态网络拓扑图（Act 3 唯一视觉高点）
2. **AgentList** — 双类 Agent 列表，徽章区分，可筛选/排序
3. **ArenaLeaderboard** — 竞技场 7 日收益排行
4. **PlazaFeed** — 战绩广场 + 分享卡（html2canvas）
5. **IntegrationGuide** — 接入指引三步式

## 1. NetworkTopology.tsx

**视觉要求**：
- 深底背景（`bg-gray-950` 或 `bg-[#0D0D14]`），白色/浅色节点和连线
- 中心节点：CoinW Logo（C 字圆形，品牌紫 `#5227FF`，大 64px）
- 内圈（官方 Agent，3 个）：紫色系节点，加"官方"徽章
- 中圈（外部 Agent，8 个）：各自 accent 颜色
- 连线：SVG `<line>` 从中心到每个节点
- 动态效果（CSS keyframes）：连线上有小圆点在流动，每条线不同速度/延迟
- 节点 hover：scale 1.1 + tooltip（名称 + 7d 收益率）

**布局实现**：
- 外层 `position: relative`，节点 `position: absolute`，用百分比 left/top 定位
- 官方 Agent 节点：约 30% 间距排列在中圈（半径约 35%）
- 外部 Agent 节点：约 45% 半径
- 不用 force-layout 库，不用 Three.js/Canvas

**流动小球 CSS（示例）**：

```css
@keyframes flowAlong {
  0%   { offset-distance: 0%; opacity: 0; }
  10%  { opacity: 1; }
  90%  { opacity: 1; }
  100% { offset-distance: 100%; opacity: 0; }
}
.dot {
  offset-path: path('M cx cy L x1 y1');  /* 用 SVG offset-path */
  animation: flowAlong 3s linear infinite;
}
```

实际实现中，把 SVG path 的 d 值作为 offset-path，每个节点一条独立的 CSS 动画，delay 用 index * 0.4s。

**统计数字条**（拓扑图下方，4 个数字）：

| 中文 key | 英文 key | Mock 值 |
|---------|---------|---------|
| `eco.boardA.stats.agents` | same | 134 |
| `eco.boardA.stats.strategies` | same | 68 |
| `eco.boardA.stats.dailyCalls` | same | 1,284,000 |
| `eco.boardA.stats.volume7d` | same | $48M |

**移动端**（< 768px）：隐藏拓扑 SVG，只显示统计数字条和 Agent emoji 列表

**Props**：

```typescript
interface NetworkTopologyProps {
  agents: Agent[];
  isZh: boolean;
}
```

## 4. PlazaFeed.tsx + ShareCard.tsx

### PlazaFeed.tsx

**布局**：瀑布式列表，桌面 2 列 `grid grid-cols-2 gap-4`，移动 1 列

**每条 Post 卡**：
```
[头像] [名称] [徽章] [时间]
[标题（加粗）]
[正文（3行截断：line-clamp-3，点击展开）]
[指标 chips：每个 chip = `bg-gray-100 rounded px-2 py-0.5 text-xs`]
[👍 likes  💬 comments  [分享按钮]]
```

**分享按钮**：点击 → 渲染 ShareCard，调用 html2canvas 下载 PNG

### ShareCard.tsx

```typescript
'use client';
import html2canvas from 'html2canvas';
import { useRef } from 'react';

interface ShareCardProps {
  post: PlazaPost;
  isZh: boolean;
  onClose: () => void;
}
```

**关键实现**：

```tsx
const cardRef = useRef<HTMLDivElement>(null);

const handleDownload = async () => {
  if (!cardRef.current) return;
  const canvas = await html2canvas(cardRef.current, {
    scale: 2,
    useCORS: true,
    backgroundColor: null,
  });
  const url = canvas.toDataURL('image/png');
  const a = document.createElement('a');
  a.href = url;
  a.download = `coinw-trade-${post.id}.png`;
  a.click();
};
```

**分享卡 DOM（在 `position: fixed; top: -9999px; left: -9999px`）**：

```tsx
<div
  ref={cardRef}
  style={{
    width: '600px',
    height: '340px',
    background: 'linear-gradient(135deg, #5227FF 0%, #1a0a7a 100%)',
    padding: '32px',
    fontFamily: '-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif',
    color: 'white',
    position: 'relative',
  }}
>
  {/* 左上：Logo + Agent 名 */}
  <div style={{ display: 'flex', alignItems: 'center', gap: '12px', marginBottom: '20px' }}>
    <div style={{ width: '32px', height: '32px', background: 'rgba(255,255,255,0.2)', borderRadius: '8px', display: 'flex', alignItems: 'center', justifyContent: 'center', fontWeight: 'bold' }}>C</div>
    <span style={{ fontSize: '14px', opacity: 0.8 }}>CoinW Agent</span>
    <span style={{ marginLeft: 'auto', fontSize: '24px' }}>{post.agentAvatar}</span>
    <span style={{ fontSize: '16px', fontWeight: 'bold' }}>{post.agentName}</span>
  </div>

  {/* 标题 */}
  <div style={{ fontSize: '22px', fontWeight: 'bold', marginBottom: '16px' }}>
    {isZh ? post.title : post.titleEn}
  </div>

  {/* 指标方块 */}
  <div style={{ display: 'flex', gap: '12px' }}>
    {Object.entries(isZh ? post.metrics : post.metricsEn).map(([k, v]) => (
      <div key={k} style={{ background: 'rgba(255,255,255,0.15)', borderRadius: '8px', padding: '8px 16px', textAlign: 'center' }}>
        <div style={{ fontSize: '20px', fontWeight: 'bold' }}>{v}</div>
        <div style={{ fontSize: '12px', opacity: 0.7 }}>{k}</div>
      </div>
    ))}
  </div>

  {/* 底部 */}
  <div style={{ position: 'absolute', bottom: '20px', left: '32px', fontSize: '12px', opacity: 0.6 }}>
    coinw.com · CoinW Agent Zone
  </div>
</div>
```

**注意**：
- 分享卡 `<div>` 用 `position: fixed; top: -9999px` 而非 `display: none`
- 所有样式用内联 style，不用 Tailwind class（html2canvas 不识别 Tailwind）
- 不引入任何网络字体

## 6. EcosystemBoard/index.tsx（汇总）

```tsx
'use client';

import { useT } from '@/i18n/LocaleContext';
import { AGENTS } from '../../data/agents';
import { ARENA_ENTRIES } from '../../data/arena';
import { PLAZA_POSTS } from '../../data/plaza';
import { NetworkTopology } from './NetworkTopology';
import { AgentList } from './AgentList';
import { ArenaLeaderboard } from './ArenaLeaderboard';
import { PlazaFeed } from './PlazaFeed';
import { IntegrationGuide } from './IntegrationGuide';

export function EcosystemBoard() {
  const t = useT();
  const isZh = t.nav.cta === 'EN';
  const eco = (t as any).ecosystem;

  return (
    <div className="space-y-20">
      <NetworkTopology agents={AGENTS} isZh={isZh} />
      <div>
        <h3 className="text-2xl font-bold text-ink mb-6">{eco.boardA.agentListTitle}</h3>
        <AgentList agents={AGENTS} isZh={isZh} />
      </div>
      <div>
        <h3 className="text-2xl font-bold text-ink mb-2">{eco.boardA.arenaTitle}</h3>
        <p className="text-muted text-sm mb-6">{eco.boardA.arenaDesc}</p>
        <ArenaLeaderboard entries={ARENA_ENTRIES} isZh={isZh} />
      </div>
      <div>
        <h3 className="text-2xl font-bold text-ink mb-2">{eco.boardA.plazaTitle}</h3>
        <p className="text-muted text-sm mb-6">{eco.boardA.plazaDesc}</p>
        <PlazaFeed posts={PLAZA_POSTS} isZh={isZh} />
      </div>
      <IntegrationGuide isZh={isZh} />
    </div>
  );
}
```
