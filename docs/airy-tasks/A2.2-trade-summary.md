# A2.2 — TradeSummary 组件（Act 2 Step 6）

**分支**：`feat/airy-a2.2-trade-summary`
**文件**：`src/modules/agent-chat/components/TradeSummary.tsx`
**预估工时**：2-3h

---

## 背景

Act 2 是 6 步用户旅程：发现 → 选 Agent → 绑 API → 对话 → 执行 → **复盘**。

Step 6 = **TradeSummary**。用户跑完一次交易后的复盘 dashboard，展示"这次 Agent 帮你做了什么 + 结果如何"。看完后"重新开始"回到 Step 1。

F 已经在 `modules/agent-chat/index.tsx` 里留好了接入点（lazy require），你交付后自动生效。

## 目标

一个"交易后复盘"dashboard，让用户看到 Agent 的价值：
- 本次会话 Agent 调了哪些 Skills
- 产出了什么（日报 / 订单 / MCP 接入等）
- 假的 PnL 数据
- "下次试试这些 Skills" 推荐

## 接口约定

```tsx
interface TradeSummaryProps {
  onNext: () => void;
}

export default function TradeSummary({ onNext }: TradeSummaryProps) { ... }
```

**导出为 default**（和 SkillDiscovery 不同，这个是 default export）——`modules/agent-chat/index.tsx` 里是 `require(...).default`。

## UI 要求

**整体结构**：标题 + 4 个指标卡 + 2 列内容（左：Skill 使用情况 / 右：关键事件时间线）+ CTA。

1. **Header**：
   - 标题："本次会话复盘" / "Session Review"
   - 副标题：日期 + 会话时长
   - 右上：大勾 + "交易完成" badge

2. **4 个指标卡**（grid-cols-4，移动端 2x2）：
   - 今日 PnL: `+$1,247 (+2.91%)`，绿色
   - 调用 Skills 数: `7`
   - 完成交易数: `2`
   - Agent 响应时长均值: `1.3s`

3. **左栏：Skill 使用明细**
   - 分组列出本次用过的 Skills（写死假数据即可）：
     - 信息端：M1 行情 / M2 排行 / M4 市场概览
     - 交易端：M5 下单 / M6 订单查询 / M7 余额
     - 认证：M11 API Key / M12 风控
   - 每个 skill 显示调用次数 + 耗时
   - 可以用 progress bar 可视化调用频次

4. **右栏：关键事件时间线**
   - 10:32 挂单 BTC/USDT @ $85,000 (0.5 BTC)
   - 10:45 BTC 触及 $85,000，订单成交
   - 11:02 Agent 建议止盈 +2%，执行
   - 11:20 MCP 对接完成，18 项 Skills 上线
   - 每条带图标 + 时间 + 描述

5. **底部 CTA**：
   - 主："重新开始会话 →" / "Start New Session →"
   - 副："导出复盘报告 PDF" （做成按钮样式即可，点击 toast "导出中..." 不需要真导出）
   - 主按钮触发 `onNext()`

**视觉锚点**：Act 1 风格。绿色用在正向指标（PnL/完成），brand 橙用在主 CTA 和 skill 高亮。不要引入新颜色。
