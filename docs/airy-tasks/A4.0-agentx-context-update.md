### 你的 Design System 需要调整的

你提的 token 全是深色背景（`#0a0518`）。方向对，但现在有 light/dark toggle，token 必须兼容两套。用 CSS variable 引用（`var(--color-ink)` 而不是硬编码 `#fff`），`.cw-dark` class 会自动切换。

具体参考：`src/styles/tokens.css` 里的 `:root`（light）和 `.cw-dark`（dark）两套值。
