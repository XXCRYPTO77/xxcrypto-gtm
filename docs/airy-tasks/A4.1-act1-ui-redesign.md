## 任务清单

### T1：Hero 视觉升级

**现状**：纯文字 + 渐变光晕背景
**目标**：加视觉元素，让 Hero 有记忆点

要做的事：
- 在 Hero 右侧（desktop）或下方（mobile）加一个 CSS/SVG 动画元素——抽象的 AI agent 视觉（粒子网络 / 神经网络节点 / 流动的光线）。不用 Three.js，纯 CSS animation + SVG 就够
- Badge 下面的 pulsing dot animation 已有（`animate-pulse`），保留
- 标题加渐变效果：`background: linear-gradient(...)` + `background-clip: text`
- Stats bar：在 CTA 按钮下方加一行数据指标。但**不要编造数据**。用技术指标代替虚假用户数据：
  - `< 200ms` 决策延迟
  - `4 维信号源` 实时接入
  - `AES-256` 加密保护
- 整体居中布局改为左文字 + 右视觉的双栏（desktop），移动端堆叠

**文件**：`src/modules/landing/components/Hero.tsx`

**验收标准**：
- Desktop 有明确的视觉焦点（不再是纯文字）
- 动画流畅，不卡顿（CSS animation，不用 JS 驱动帧循环）
- 移动端正常堆叠，不溢出

### T2：HowItWorks 时间线连接

**现状**：三张独立卡片，无视觉流动感
**目标**：卡片之间有连接线/时间线，传达 "进化路径" 的概念

要做的事：
- Desktop：三卡横排之间加 SVG/CSS 连接线（渐变色，从蓝到紫到绿）
- 连接线上有圆点标记每个阶段
- 每张卡片左侧加 accent border（Stage 1 蓝、Stage 2 紫、Stage 3 绿）
- 可选：scroll reveal animation（Intersection Observer，卡片依次 fadeUp）
- Mobile：连接线改为左侧竖线

**文件**：`src/modules/landing/components/HowItWorks.tsx`

**验收标准**：
- Desktop 有明显的 1→2→3 流动感
- Mobile 竖排也有连接感
- 颜色用 token（`text-brand`、`border-brand` 等）

### T6：Responsive 优化

所有现有组件 + T1-T5 新增组件做响应式检查：

断点：
- `< 640px`：单栏，padding 收紧
- `640px - 1024px`：两栏适配
- `> 1024px`：三栏完整布局

重点：
- Hero 双栏 → 移动端单栏堆叠
- 卡片 grid → 移动端单列
- 文字 `clamp()` 或 `sm:` / `md:` 断点控制字号
- CTA 按钮移动端全宽
