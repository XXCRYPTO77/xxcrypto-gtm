## 1. RevenueRules.tsx

**用途**：用两张对比卡清楚说明分润规则。

**布局**：
```
[标题：官方 Agent 独有]
[副标题]

┌─────────────────────┐  ┌─────────────────────┐
│  官方 Agent 调用      │  │  外部 Agent 调用      │
│  ✓ 贡献者分润         │  │  ✗ 不分润             │
│  (绿色卡片)          │  │  (中性/灰色卡片)      │
└─────────────────────┘  └─────────────────────┘

[解释段落："为什么这样设计"]
```

**绿色卡片**：`bg-green-50 border border-green-200 rounded-xl`，大号绿色 ✓
**灰色卡片**：`bg-gray-50 border border-gray-200 rounded-xl`，大号灰色 ✗

**文案**：
- 标题：`eco.boardC.rulesTitle`
- 副标题：`eco.boardC.rulesDesc`
- 绿色卡标题：`eco.boardC.officialHit`
- 灰色卡标题：`eco.boardC.externalHit`
- 解释：`eco.boardC.whyTitle` + `eco.boardC.whyDesc`

**Props**：

```typescript
interface RevenueRulesProps {
  isZh: boolean;
}
```

## 2. RevenueCalculator.tsx

**用途**：让访客拖动 slider 看预期分润收益，底部有 disclaimer。

**布局**：
```
[标题：预期分润（演示）]
[disclaimer 标注：示意参数，上线以公告为准]

月调用次数：[─────●─────────] 20,000

预期收益：
┌──────────┐  ┌──────────┐
│ 1,000    │  │ ~$100    │
│ Credit   │  │ USDT     │
└──────────┘  └──────────┘

计算公式（演示用）：
月调用次数 × 0.05 Credit/次 = 预期 Credit
Credit : USDT = 10 : 1（演示参数）
```

**Slider**：
- 范围：1,000 → 100,000（步进 1,000）
- 默认值：20,000
- 用 `<input type="range">`，自定义 Tailwind 样式

**计算逻辑**（演示参数，不代表真实规则）：

```typescript
const credit = Math.round(calls * 0.05);
const usdt = (credit / 10).toFixed(0);
```

**Disclaimer 样式**：
- 黄色警告条 `bg-yellow-50 border border-yellow-200 rounded-lg text-yellow-800 text-xs`
- 文案：`eco.boardC.calculatorDisclaimer`

**Props**：

```typescript
interface RevenueCalculatorProps {
  isZh: boolean;
}
```

## 3. ContributorTiers.tsx

**用途**：展示三级贡献者准入，当前只做展示（门槛用占位）。

**布局**：三张卡片并排（桌面），移动端竖排

**三级**：

| 级别 | 颜色 | 门槛（占位） |
|------|------|-----------|
| 社区贡献者 | 灰色 `#6B7280` | 无门槛，任何人可发布 |
| 认证开发者 | 蓝色 `#2563EB` | KYC + 最低入金（TBD） |
| 官方合作伙伴 | 紫色 `#7C3AED` | 审核 + 收益率达标（TBD） |

**每张卡**：
```
[颜色图标圆圈]
[级别名称]
[门槛描述]（占位文案）
[每级独有权益（1-3条）]
```

**权益对应**（硬编码文案，i18n 用 `eco.boardC` 里的 key）：
- 社区：发布策略卡 / 被所有 Agent 调用 / 社区排行展示
- 认证开发者：优先展示位 / 贡献者认证徽章 / 分润收益
- 官方合作伙伴：联合推广 / 独家策略位 / 深度合作分润

**底部**：`eco.boardC.tierNote`（灰色小字，占位说明）

**Props**：

```typescript
interface ContributorTiersProps {
  isZh: boolean;
}
```

## 4. RevenueBoard/index.tsx（汇总）

```tsx
'use client';

import { useT } from '@/i18n/LocaleContext';
import { RevenueRules } from './RevenueRules';
import { RevenueCalculator } from './RevenueCalculator';
import { ContributorTiers } from './ContributorTiers';

export function RevenueBoard() {
  const t = useT();
  const isZh = t.nav.cta === 'EN';
  const eco = (t as any).ecosystem;

  return (
    <div className="space-y-16">
      <RevenueRules isZh={isZh} />
      <div>
        <h3 className="text-2xl font-bold text-ink mb-2">{eco.boardC.calculatorTitle}</h3>
        <RevenueCalculator isZh={isZh} />
      </div>
      <div>
        <h3 className="text-2xl font-bold text-ink mb-6">{eco.boardC.tierTitle}</h3>
        <ContributorTiers isZh={isZh} />
        <p className="text-center text-xs text-muted mt-4">{eco.boardC.tierNote}</p>
      </div>
    </div>
  );
}
```
