## Dark theme rules

The Arena page wrapper (`act3/arena/page.tsx`) currently uses light `bg-page`. You have two options:

**Option A (recommended):** Wrap ArenaBoard content in a dark container:
```tsx
<div className="bg-[#0D0D14] -mx-6 -mt-10 px-6 pt-10 pb-16 sm:-mx-6 sm:px-6 rounded-none">
  {/* all arena content here, white text */}
</div>
```

**Option B:** Ask Dan to change `arena/page.tsx` main bg to dark. Then F will update.

Either way: **ALL text must use `text-white` / `text-white/60` / `text-white/40`**. Do NOT use `text-ink` or `text-muted` — those are calibrated for light backgrounds and will be invisible on dark.
