## 数据内容（4 张场景卡）

4 个场景，你来写 prompt 内容。要求：**prompt 必须是真实可用的**，用户复制粘贴进 Claude Desktop、ChatGPT 或任何支持 MCP 的 Agent 就能直接跑，不是示意用的假 prompt。

| id | icon | title | subtitle | prompt 方向 |
|----|------|-------|----------|-------------|
| daily-report | 📰 | 每日加密日报 | 每天早上自动整理市场动态 | 调用 M1+M2，生成今日 BTC/ETH/主流币涨跌 + 24h 成交量变化 + 一句话市场情绪判断 |
| price-alert | 🔔 | 价格提醒 | 跌到目标价立刻通知我 | 调用 M1，监控某个币种价格，低于/高于某阈值时说"到了，当前价格是 XXX" |
| portfolio | 📊 | 持仓总览 | 一句话看清所有仓位盈亏 | 调用 M7+M8，返回当前余额 + 持仓 + 每个仓位盈亏百分比 |
| auto-trade | ⚡ | 挂限价单 | 说一句话帮你挂好单 | 调用 M5，用自然语言描述（"BTC 跌到 85000 帮我买 0.1 个"）转成限价单挂单请求 |

**写 prompt 的注意事项**：
- 以"你是 CoinW Agent Skills 助手..."开头设置 context
- 明确写出调用哪个 Skill（`use_coinw_skill("market_data")` 这类形式）
- 结尾说明返回格式
- 每个 prompt 控制在 3-6 句话，不要太长
