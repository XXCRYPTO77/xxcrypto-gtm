## Act II · 能托管（v1.1 CWClaw 认养流程）

**入口**：https://xxcrypto-gtm.vercel.app/act2  
**时长**：5 分钟

### 开场定调（30 秒）

> "Act II 是完整的用户上手路径——从认养一个专属 Agent，到第一笔 AI 辅助交易，六步走完。"

顶部 JourneyBar 显示六步进度：认养 / 绑定账号 / 性格调教 / 取名 / 首次对话 / 今日复盘。

### Step 1 — 认养落地页（30 秒）

**停留在 Hero 区。**

> "第一屏就把产品说清楚了：这是你的专属加密交易 Agent，由 CoinW 驱动。三个数字——18 项核心 Skill、7×24h 在线、0 提现权限。"

指出三张 Feature 卡（读懂仓位 / 有性格的对话 / 指令即交易），**不逐条读，扫一眼带过。**

**点击"开始认养 →"进入 Step 2。**

### Step 2 — CoinW 绑定（45 秒）

**点击"CoinW 授权登录"。**

观察动画：
- Step 1 → 连接账号（绿色对号）
- Step 2 → 自动生成 API Key（进度条推进）
- Step 3 → UID 绑定完成，Key 显示

> "这里有两个关键点：一是不需要用户手动配置 API Key，系统自动生成；二是 Key 的权限写死了——只读加现货交易，禁止提现。这是安全设计的底线，不是可选项。"

**点击"继续调教性格 →"进入 Step 3。**

### Step 3 — 性格调教（1 分钟）

三屏引导，**每屏选一个后点"下一步"，不要停留解释。**

- 第一屏：**选"激进猎手"**（UI 变红色主题）
- 第二屏：**选"全仓扫荡"**
- 第三屏：**选"实时轰炸"**

> "四种风格 × 四种偏好 × 三种推送频率——排列组合出来就是你的专属 CWClaw。每次选择界面颜色和视觉元素都会跟着变，用户感知到的是'这是我自己的东西'。"

**点击"调教完成 →"进入 Step 4。**

### Step 4 — 取名（30 秒）

**在输入框里打一个名字，比如"Alpha"。**

观察：右侧/上方的 CWClaw 头像颜色跟着刚才选的风格（激进猎手 = 红色渐变）实时渲染。

> "取完名字，这个 Agent 就是用户自己的了。不是系统分配的，是认养的。"

**点击"认养完成，开始对话 →"进入 Step 5。**

### Step 5 — 首次对话（1 分 30 秒）

进入 Chat 界面。右侧面板显示的不是 Skill 列表，是这个 Agent 的快捷操作面板：

- 顶部：Agent 头像 + "Alpha · 在线"（红色主题跟着风格走）
- 四个快捷按钮：行情 / 持仓 / 委托 / 活动
- 三个账号链接：API Key / App 下载 / 升级 Pro

**点击右侧"行情"快捷按钮。**

观察 Chat 区：
- 工具调用气泡出现（M1/M4 Skill loading）
- 回复：BTC 实时价格 + 涨幅 + 市场判断
- 右下角出现提示 chip，引导下一步

**输入"帮我买 BTC"或点击 chip。**

> "一句话下单。Agent 完成：行情确认 → 余额检查 → 鉴权 → 提交限价单。用户不需要打开交易界面。"

限价单卡片出现后，**点击"执行交易 →"进入 Step 6。**

### Step 6 — 今日复盘（30 秒）

标题自动显示"Alpha 今日的表现"。

> "PnL、调用了哪些 Skill、每笔操作的时间线，一页全展示。这是 v1.1 的收尾——让用户知道 Agent 帮他做了什么，而不是黑盒跑完什么都没说。"

**快速扫四个指标卡（PnL / Skills 使用 / 交易笔数 / 平均延迟），不需要逐个解读。**

## 收尾（给演示者）

### 常见追问

**Q：真实 API 什么时候能接？**  
> 这个 demo 是 mock，真实接法已在 API Matrix 里展示（Act IV → API 矩阵）。后端工作量约 2-3 个月，前端这套壳可以直接复用。

**Q：安全怎么保证？**  
> 分三层：API Key 权限分级（无提现权限）、风控引擎（单笔限额+IP 白名单）、大额二次确认。具体看 Act IV 安全架构。

**Q：用户从哪来？**  
> 两条路：一是 GEO/MCP Registry 被 Agent 社区自然发现（Act I 的 M14 Skill 可发现性）；二是站内落地页对接现有用户（M15）。具体运营方案另行提报。

**Q：这和竞品有什么不同？**  
> 我们是交易所原生的 MCP 服务，不是第三方对接。API Key 直接绑定账户，不需要用户给第三方平台授权，安全链路更短。

### 结尾推进

> "这是两天做出来的。正式排期给两个月，我们可以交付生产级代码。"
