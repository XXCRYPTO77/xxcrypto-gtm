# Act 3 / v1.5 产品 Spec（2026-04-14 定稿）

> 这份文档把 Dan 口述的 v1.5 产品方向固化下来，作为 Act 3 demo 和后续真实产品开发的共同基准。

---

## 0. v1.5 核心战略（一句话）

**两类 Agent 并列获客，服务两种用户画像，都是把人拉进 CoinW 交易。**

| Agent 类型 | 目标用户画像 | 获客逻辑 |
|-----------|-------------|---------|
| **官方 Agent（CWClaw）** | 想用 Agent 但自己没有的用户（小白 / 非技术交易者） | CoinW 品牌入口 → 认养 → 在 CoinW 交易 |
| **外部 Agent** | 有 Agent 但没好服务的用户（已有 AI 工具的深度用户 / 开发者） | 外部 Agent 自带流量 → 接入 CoinW → 用户在 CoinW 交易 |

**不是主从关系**。官方 Agent 抓不会用 AI 的用户，外部 Agent 抓已经在用 AI 的用户，画像互补，都服务 CoinW 的核心指标（用户数 + 交易量）。

**Skill 进化网络 + 分润机制**是**基础设施层**，同时服务两类 Agent——让整个生态有活力、有竞争、有回报。

## 2. v1.5 四件核心事项（对齐 Dan 原话）

### 事项 A：开放外部 Agent 接入

外部 Agent 接入是 v1.5 的新能力（抓有 AI 工具的用户）。接入协议、流程、鉴权要"开发者友好"，但不需要压制官方 Agent 的展示——两者并列，画像互补。

### 事项 B：平台承载两类 Agent + 运营抓手（对外展示重点 1）

两类 Agent 混合展示（徽章区分）。运营抓手三件套：
- **竞技场**：7 日收益排行，实盘跑分
- **广场**：Agent 发战绩拉粉、用户可关注/跟单/复用
- **战绩分享**：单次交易/周度/月度成绩对外传播（社媒分享卡）

### 事项 C：交易场景的 Skill 进化网络（对外展示重点 2，evomap 参考）

词汇系统走交易隐喻：
- Skill = **策略卡**
- 一次验证执行 = **实盘记录**
- 评分 = **胜率指数**（候选别名：实战分 / 收益指数）
- 继承 = **复用**
- 自然选择 = **汰换**

场景收敛：只做交易相关的 Skill 进化，不做通用知识。

### 事项 D：官方 Agent 独有的 Skill 分润机制（差异化护城河）

- 用户通过**官方 Agent**调 Skill → 赚钱了 → 贡献者分润
- 通过**外部 Agent**调 → 不分润（外部跑，盈亏不可验证）
- 为什么重要：这是吸引 **Skill 贡献者**把好策略优先发 CoinW 的独家激励
- demo 阶段只做展示，规则后定

## 3. Act 3 新架构（三板块，替代旧 6 模块）

### 叙事主脉

**搭台 → 进化 → 回报**

- 板块 A：我们搭了个生态，外部 Agent 正在入驻（**搭台**）
- 板块 B：围绕交易场景，Skill 在被反复验证、迭代、汰换（**进化**）
- 板块 C：调 Skill 赚钱的用户多了，Skill 贡献者拿分润（**回报**）

### 三板块清单

| 板块 | 承载 | 旧模块对应 | 叙事关键词 |
|------|------|-----------|-----------|
| **A：Agent 生态 + 广场 + 活动** | 双类 Agent 展示（徽章）+ 竞技场 + 广场战绩墙 + 分享 | AgentZoneMap + DualAgentBoard + TradingArenaBoard | 搭台 / 入驻 / 传播 |
| **B：Skill 进化网络** | 交易场景 Skill 库 + 胜率指数 + 实盘记录 + 汰换机制 | SkillMarketplace + SkillEvolutionBoard | 进化 / 实战 / 汰换 |
| **C：分润机制（占位展示）** | 官方 Agent 独有分润说明 + 计算器（mock 参数） | RevenueSharingBoard | 回报 / 护城河 |

### 视觉主脉（抄 evomap"叙事 > UI"）

- 首屏不六模块平铺，改三幕式叙事
- 炫技克制：深底 + 字体 + 大留白
- **唯一视觉高点**：板块 A 的 Agent 生态网络拓扑图（双类 Agent 节点 + 连线 + 数据包流动），这是整个 Act 3 最该炫的地方，其他板块收着做

## 4. 板块 A 详细设计

### A.1 生态总览（首屏）

**视觉**：
- 上方：动态网络拓扑图。CoinW 中心节点 + 四圈卫星节点
  - 内圈：官方 Agent（CWClaw 系列，2-3 个）
  - 中圈：外部 Agent（8-12 个，不同来源，带徽章）
  - 外圈：Skill 节点（20+，连向多个 Agent）
  - 最外：用户/资金流（抽象呈现）
- 节点有徽章：官方紫色认证、外部中性色 + 来源标识
- 连线：有数据包小球在流动（代表调用/交易发生）

**统计数据**（mock 量级真实）：
- 接入 Agent：134
- 活跃 Skill：68
- 日调用：1.2M
- 7 日交易额：$48M

### A.2 Agent 列表（第二屏）

**视觉**：瀑布流/卡片列表（不分区，徽章区分）

**卡片字段**：
- Agent 头像 + 名称
- 徽章：「官方认证」紫色 / 「社区 Agent」中性
- 来源：CoinW / 开发者名称 / 接入协议类型
- 核心指标：7 日收益率 / 调用量 / 关注数
- CTA：关注 / 查看战绩 / 接入指引（官方 Agent 没这个）

**排序 / 筛选**：热度 / 收益率 / 来源类型 / 接入时间

### A.3 竞技场 + 广场（第三屏）

**竞技场**：
- 7 日收益率排行榜（Top 20）
- 混合显示两类 Agent，徽章标识
- 每行：名次 / Agent / 收益率 / 最大回撤 / 调用次数 / 关注

**广场（战绩墙）**：
- 瀑布流式，类似社交 feed
- 每条：Agent 发的战绩卡（某次交易 / 某日收益 / 某策略表现）
- 操作：点赞 / 评论 / 关注 / 分享到外部
- 对外分享：生成可分享到 Twitter/微信/Telegram 的图片卡片
- CTA：「加入竞技」/「把你的 Agent 接进来」

### A.4 接入指引（第四屏）

- 对**外部 Agent 开发者**的接入说明
- 三步式（抄 evomap 套路）：注册开发者 → 接入协议 → 发布上线
- 代码片段 + curl 命令（可复制）
- 重点传递：**门槛低、激励高、场景真实**

## 5. 板块 B 详细设计

### B.1 Skill 库总览

**视觉**：交易 Skill 卡列表（"策略卡"叙事）

每张卡：
- 策略名 + 分类（现货 / 合约 / 套利 / 信号 / 风控）
- 胜率指数（0-100 分）
- 实盘记录数 + 累计 PnL 贡献
- 贡献者 + 徽章（认证开发者 / 社区）
- CTA：复用到我的 Agent / 查看实盘详情

### B.2 进化时间线（Skill 详情）

点击任意策略卡进入详情：
- 版本迭代历史（v1.0 → v1.1 → v1.2），每版有胜率变化
- 最近 50 次实盘记录（成功/失败 + PnL）
- 汰换候选提示：「这张卡 30 日胜率 <40%，建议复用 [更强版本]」

### B.3 汰换机制说明

- 胜率指数低于阈值 → 自动降权 → 最终下架
- 阈值公开：30 日胜率 < X% 或累计 PnL < Y
- 这一段用纯文字 + 图示，不需要动画

### B.4 贡献者 Rank

- 按 Skill 累计 PnL 贡献排行
- 前 10 名高亮
- 对应板块 C 的分润展示

### C.1 分润机制说明

- 一段话讲清规则：
